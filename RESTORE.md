# Восстановление в другом аккаунте Perplexity

1. Откройте **Plugins** в новом аккаунте.
2. Для каждого нужного skill нажмите **Add custom** и загрузите файл из `skills/`.
3. Для кастомного plugin создайте архив или публичный GitHub-репозиторий со структурой `SKILL.md` и `mcp.json`, затем импортируйте его через **Plugins → Add custom**.
4. Откройте **Plugins → Discover**, найдите нужный plugin и нажмите **Install**.
5. На этапе **Connect your accounts** подключите только необходимые коннекторы.
6. В **Plugins → Installed** проверьте статус каждого коннектора; при ошибке используйте **Reconnect**.

Не добавляйте токены и секреты в репозиторий: храните их в GitHub Secrets или менеджере секретов.
