# Perplexity export

Этот репозиторий содержит переносимый набор для восстановления Perplexity-конфигурации в другом аккаунте.

## Содержимое
- `connectors/connected-connectors.md` — перечень подключённых коннекторов и их статусов.
- `skills/SKILL-template.md` — шаблон для переноса пользовательских skills.
- `plugins/mcp-json-template.json` — шаблон конфигурации MCP/коннекторов.
- `RESTORE.md` — пошаговая инструкция восстановления в другом аккаунте.

## Важно
OAuth-токены, cookies, пароли и авторизации коннекторов не переносятся. В новом аккаунте каждый коннектор необходимо заново подключить и авторизовать.
